# 📊 HR Analytics Dashboard – Power BI

## 📌 Project Overview
This project is an interactive HR Analytics Dashboard developed using Microsoft Power BI. The dashboard analyses employee data to provide insights into workforce demographics, employee attrition, job satisfaction, salary distribution, overtime, and departmental performance.

The objective of this project is to demonstrate how HR data can be transformed into meaningful business insights to support data-driven workforce decisions.

## 🎯 Key Objectives
- Analyse overall employee attrition
- Identify departments and job roles with higher attrition
- Analyse attrition across different age groups
- Compare employee attrition by gender
- Understand the relationship between overtime and attrition
- Analyse attrition across salary groups
- Explore employee job satisfaction
- Monitor key HR workforce metrics

## 📊 Dashboard KPIs
The dashboard includes key HR metrics such as:

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Employee Age
- Average Experience

## 📈 Dashboard Visualisations
The dashboard includes:

- Attrition by Department
- Attrition by Job Role
- Attrition by Age Group
- Attrition by Gender
- Attrition by Salary Slab
- Attrition by Overtime
- Attrition Rate by Overtime
- Attrition by Job Satisfaction
- Department filtering and interactive analysis

## 🛠️ Tools & Skills Used
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualisation
- KPI Development
- Interactive Dashboard Design
- HR Data Analysis

## 💡 Key Insights
The dashboard enables users to quickly identify workforce patterns and areas with higher employee attrition. HR teams can use these insights to investigate factors such as job role, salary, overtime, age group, and job satisfaction that may contribute to employee turnover.
